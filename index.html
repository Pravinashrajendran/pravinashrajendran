Learning note: the real project checks Cowrie event fields and runs on a schedule via cron. A threshold is a simple rule, not proof that an IP is malicious.

What the real pipeline does

Observe

Cowrie records interactions with the SSH/Telnet honeypot.

Parse and inspect

JSON event records can be processed by Python and separately shipped through Logstash into Elasticsearch for Kibana visualisation.

Decide and respond

The script checks its configured threshold and can add an iptables DROP rule. Cron scheduling means this is periodic, not instant.

Important limitations

  • Repeated events are not automatically the same as confirmed malicious intent.
  • Threshold logic can create false positives; validate before blocking.
  • Firewall rules need expiry, review and cleanup to avoid unbounded growth.
  • Use an isolated lab and never test against systems without permission.

THE BIG PICTURE

What happens, and why?

Both projects follow the same security cycle, but they use evidence in different ways.

👁️

1. Observe

Collect logs from a honeypot, operating system, or web server. Without events, there is nothing to investigate.

🔎

2. Detect

Use a rule or search to find a pattern — for example, repeated failed logins. Detection creates a lead, not certainty.

🧠

3. Investigate

Check the source, time window, event context, and whether the behaviour could be legitimate before taking action.

🧱

4. Respond

A firewall may block an address, while a SOC analyst may escalate an alert. Response should be proportionate and reversible.

📈

5. Visualise

Dashboards summarise event volume and patterns so analysts can see changes and prioritise investigations.

🔁

6. Improve

Review false positives, tune thresholds, document decisions, and test whether the workflow still works as expected.

PLAIN-ENGLISH GLOSSARY

Tools without the jargon

Quick definitions you can use while studying or explaining the projects in an interview.

🍯 Honeypot (Cowrie)

A decoy service designed to record interactions that may reveal scanning or login attempts. It is not a normal production login server.

📄 JSON log

A structured text record made of named fields. Scripts and log pipelines can read fields more reliably than unstructured text.

🐍 Python threshold rule

A small program that counts events and compares them with a configured limit. Simple to explain, but it can misclassify behaviour.

🧱 iptables

A Linux firewall interface that manages packet-filtering rules. A DROP rule discards matching traffic; rules must be applied carefully.

🔍 Splunk + SPL

Splunk indexes and searches machine data. SPL is its search language for filtering events, aggregating counts, and preparing visualisations.

📦 Logstash / Elasticsearch / Kibana

Logstash can parse and forward events, Elasticsearch stores and searches indexed data, and Kibana explores it visually. This path is separate from Splunk.
